# Comprenticeship

A free, open method for community-based learning. The community is the teacher, and the student is the apprentice: learning **with** the community, not for it.

This repository holds the one-page website that introduces the idea.

## What's here

| File | What it is |
| --- | --- |
| `index.html` | The website: The Story (with the origin of the word), How It Works (with a section for community partners), The Canvas (an interactive planner), and The Syllabus |
| `Comprenticeship_Canvas.pdf` | The printable one-page Comprenticeship Canvas |
| `UNIV_1015_Comprenticeship_Syllabus.pdf` | The draft sample syllabus, downloadable from the site |
| `source/UNIV_1015_Comprenticeship_Syllabus.docx` | The editable Word version of the syllabus |

## Viewing it

The site is a single page with no build step. Open `index.html` in a browser, or deploy the folder as a static site (for example on Vercel).

## Status

Comprenticeship is a proposed model. The syllabus is a draft template: course codes, office names and other bracketed details are placeholders for a school to replace with its own.
